# Product Inventory Search

### 📝 Description
A foundational linear search algorithm designed to query indexed string datasets. The application initializes a 5-element array (`productList`) and compares a target input string (`searchQuery`) sequentially against every index position. Utilizing a boolean state flag (`isFound`), the system provides exact index mapping upon matching or outputs an explicit fallback error message if the query fails.

### 🛠️ Technologies
* VisuAlg (Pascal/Pseudocode)

### 🚀 How to Run
1. Open [VisuAlg Web](https://visualg.com.br/).
2. Paste the code from `product-inventory-search.alg`.
3. Run the program.
