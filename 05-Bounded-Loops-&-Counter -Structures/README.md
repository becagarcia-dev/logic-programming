# Module 05: Bounded Loops & Counter Structures

### 📝 Description
This module focuses on deterministic iteration mechanics, counter-driven execution blocks, and controlled sequence traversal using fixed `for` (`para`) loops. The challenges cover financial accumulation, network latency analysis for boundary extremes (min/max values), countdown telemetry with negative step decrements, and voting frequency tallying.

### 📊 Bounded Loops Reference
This mapping details how counter-driven loops and step modifiers function in this section:

| VisuAlg Keyword | English Equivalent | Category | Description |
| :--- | :--- | :--- | :--- |
| `para ... ate ... faca` | `for ... to ... do` | Counter Control | Initiates a deterministic loop block executing across a fixed range. |
| `fimpara` | `end for` | Control Flow | Marks the end boundary of the bounded loop scope. |
| `passo -1` | `step -1` | Offset Modifier | Decrements the loop index automatically on each pass for countdowns. |

### 📂 Challenges Included
* **`01-sales-commission-calculator/`** - Sales Commission Calculator (Processes revenue across sales representatives to accumulate total income and average performance).
* **`02-server-ping-latency-analyzer/`** - Server Ping Latency Analyzer (Evaluates telemetry metrics across network nodes to find peak and optimal latency response times).
* **`03-rocket-launch-countdown/`** - Rocket Launch Countdown (Utilizes negative step offsets to execute a decrementing launch sequence).
* **`04-voting-tally-system/`** - Voting Tally System (Logs discrete user choices, updates tally counters, and calculates proposal approval rates).
