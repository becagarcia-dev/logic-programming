# Module 06: Data Arrays & Indexed Structures

### 📝 Description
This module focuses on data persistence, indexing mechanics, and multi-variable state management using fixed-size arrays (`vetor`). The challenges explore linear memory allocation, parallel array indexing, batch data collection, comparative statistical thresholds, and search algorithms executed through bounded loop operations.

### 📊 Arrays & Indexing Reference
This mapping details how array declarations, indexing operations, and traversal loops function in this section:

| VisuAlg Keyword | English Equivalent | Category | Description |
| :--- | :--- | :--- | :--- |
| `vetor [1..N] de tipo` | `array [1..N] of type` | Data Structure | Allocates a fixed-size contiguous memory sequence for a specific data type. |
| `array[index]` | `array[index]` | Memory Access | Accesses or updates a value at a specific 1-based index position. |
| `para i de 1 ate N faca` | `for i from 1 to N do` | Array Traversal | Executes a bounded loop to iterate sequentially through array positions. |

### 📂 Challenges Included
* **`01-apparel-inventory-catalog/`** - Apparel Inventory Catalog (Pairs multi-type collection metrics using synchronized string and real parallel arrays).
* **`02-weekly-temperature-monitor/`** - Weekly Temperature Monitor (Logs daily thermal metrics, computes arithmetic averages, and evaluates above-threshold frequencies).
* **`03-product-inventory-search/`** - Product Inventory Search (Implements a linear search algorithm across indexed string datasets with boolean query validation).
* **`04-student-grade-classifier/`** - Student Grade Classifier (Processes student names and grades simultaneously to evaluate and classify academic approval status).
