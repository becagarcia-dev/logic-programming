# ATM Interactive Menu

### 📝 Description
An interactive terminal menu utility engineered using post-tested iteration mechanics (`repeat ... until` / `repita ... ate`). The system presents a simulated banking console featuring balance inquiry, deposit processing, and fund withdrawal functionality. The loop guarantees execution of the interface menu on initial launch and maintains application execution state until the explicit exit option (`0`) is selected.

### 🛠️ Technologies
* VisuAlg (Pascal/Pseudocode)

### 🚀 How to Run
1. Open [VisuAlg Web](https://visualg.com.br/).
2. Paste the code from `atm-interactive-menu.alg`.
3. Run the program.
