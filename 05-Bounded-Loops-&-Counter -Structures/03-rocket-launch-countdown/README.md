# Rocket Launch Countdown

### 📝 Description
A countdown sequence engine engineered to process negative step iterations using the `step -1` (`passo -1`) loop modifier. The program takes a user-defined initial time constraint in seconds (`initialSeconds`) and executes a decrementing `for` (`para`) loop down to zero. At each iteration, the system logs real-time telemetry markers, executing an ignition trigger upon reaching the zero state boundary.

### 🛠️ Technologies
* VisuAlg (Pascal/Pseudocode)

### 🚀 How to Run
1. Open [VisuAlg Web](https://visualg.com.br/).
2. Paste the code from `rocket-launch-countdown.alg`.
3. Run the program.
