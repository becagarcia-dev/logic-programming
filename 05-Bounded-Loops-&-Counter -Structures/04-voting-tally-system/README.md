# Voting Tally System

### 📝 Description
A decision tallying engine engineered to process discrete voting metrics and evaluate group consensus. Operating within a fixed 5-iteration `for` (`para`) loop, the system captures numeric inputs mapping to discrete choice outcomes (`1` for Approve, `2` for Reject). The application updates conditional counter states (`approvedVotes` and `rejectedVotes`) and computes the final proposal approval percentage (`approvalPercentage`).

### 🛠️ Technologies
* VisuAlg (Pascal/Pseudocode)

### 🚀 How to Run
1. Open [VisuAlg Web](https://visualg.com.br/).
2. Paste the code from `voting-tally-system.alg`.
3. Run the program.
