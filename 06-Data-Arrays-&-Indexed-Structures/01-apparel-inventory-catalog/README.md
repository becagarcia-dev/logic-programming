# Apparel Inventory Catalog

### 📝 Description
A fundamental array-based data management application designed to store and pair multi-type collection metrics. The program uses two parallel indexed array structures (`clothingItem` string array and `itemPrice` real array) bound by a unified `for` (`para`) loop. It captures input items, pairs them sequentially by index position, and prints a formatted summary catalog to the interface.

### 🛠️ Technologies
* VisuAlg (Pascal/Pseudocode)

### 🚀 How to Run
1. Open [VisuAlg Web](https://visualg.com.br/).
2. Paste the code from `apparel-inventory-catalog.alg`.
3. Run the program.
