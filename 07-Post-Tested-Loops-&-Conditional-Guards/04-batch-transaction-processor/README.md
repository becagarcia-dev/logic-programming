# Batch Transaction Processor

### 📝 Description
A financial batch processing utility designed to aggregate sequential transaction amounts via user-confirmed repetition loops (`repeat ... until` / `repita ... ate`). The system continuously prompts for monetary input values, updates a cumulative total volume tracker (`totalBatchAmount`), and checks for user confirmation after each cycle to either continue or finalize the batch session.

### 🛠️ Technologies
* VisuAlg (Pascal/Pseudocode)

### 🚀 How to Run
1. Open [VisuAlg Web](https://visualg.com.br/).
2. Paste the code from `batch-transaction-processor.alg`.
3. Run the program.
