# Custom Interval Counter

### 📝 Description
An adaptive iteration engine designed to process dynamic sequences using fixed-step loop control. The program accepts user-defined parameters for start boundaries, target limits, and step increments or decrements. By leveraging the `step` (`passo`) modifier inside a bounded `for` (`para`) loop, the system automates counter progression across positive and negative sequence bounds without manual state assignment.

### 🛠️ Technologies
* VisuAlg (Pascal/Pseudocode)

### 🚀 How to Run
1. Open [VisuAlg Web](https://visualg.com.br/).
2. Paste the code from `custom-interval-counter.alg`.
3. Run the program.
