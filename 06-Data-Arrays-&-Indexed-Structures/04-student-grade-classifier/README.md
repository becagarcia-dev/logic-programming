# Student Grade Classifier

### 📝 Description
An academic performance classification engine that pairs string identifiers with numerical evaluation metrics. The application leverages two parallel arrays (`studentName` and `finalGrade`) populated through a synchronized `for` (`para`) loop. Upon data collection, a second traversal evaluates each record against a passing threshold ($\ge 7.0$) to categorize students into approved or rejected academic status.

### 🛠️ Technologies
* VisuAlg (Pascal/Pseudocode)

### 🚀 How to Run
1. Open [VisuAlg Web](https://visualg.com.br/).
2. Paste the code from `student-grade-classifier.alg`.
3. Run the program.
