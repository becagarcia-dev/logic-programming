# Weekly Temperature Monitor

### 📝 Description
A two-pass array analytical utility engineered to log daily thermal metrics and compute comparative thresholds. The system initializes a pre-populated array of day identifiers (`weekDay`), populates a parallel float array (`temperature`), and computes the weekly arithmetic average. A secondary evaluation pass compares each array entry against the mean to calculate the frequency of above-average temperature events.

### 🛠️ Technologies
* VisuAlg (Pascal/Pseudocode)

### 🚀 How to Run
1. Open [VisuAlg Web](https://visualg.com.br/).
2. Paste the code from `weekly-temperature-monitor.alg`.
3. Run the program.
