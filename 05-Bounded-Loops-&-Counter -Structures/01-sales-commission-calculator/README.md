# Sales Commission Calculator

### 📝 Description
A financial accumulator engine designed to process sales revenue across a fixed group of sales representatives. The application uses a bounded `for` (`para`) loop to capture individual revenue inputs, continuously updating a running sum variable (`totalSales`). Post-execution, the system computes the group's arithmetic mean (`averageSales`) and displays a structured financial revenue report.

### 🛠️ Technologies
* VisuAlg (Pascal/Pseudocode)

### 🚀 How to Run
1. Open [VisuAlg Web](https://visualg.com.br/).
2. Paste the code from `sales-commission-calculator.alg`.
3. Run the program.
